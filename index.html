Men Haqimda

Men veb-dasturlash olamiga qiziqib, o'z ustimda ishlayotgan boshlang'ich dasturchiman. Hozirgi kunga qadar veb-sahifalarning tuzilishini belgilash (HTML), ularni bezash (CSS, Bootstrap) va loyihalarni internetga joylash texnologiyalarini muvaffaqiyatli o'zlashtirdim.

Shuningdek, kodlarimni xavfsiz saqlash va boshqarish uchun Git va GitHub hamda ularni tarqatish uchun Netlify platformalaridan foydalanishni o'rgandim. Oldinda esa JavaScript va boshqa qiziqarli texnologiyalar turibdi!
